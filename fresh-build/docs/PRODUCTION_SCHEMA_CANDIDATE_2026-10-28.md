## 28 October read-only follow-up

Staging and production each list 33 migrations with the same ordered names. Their generated migration version timestamps differ because the projects were applied separately. The production security advisor reports 59 informational deny-all RLS notices, one anonymous published-post RPC notice, and 80 authenticated guarded-definer RPC notices. The anonymous RPC and definer grants remain subject to the issued-session and output-projection tests, and indexes need representative workload evidence before a change. [RLS advisor](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy), [definer advisor](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable), [foreign-key index advisor](https://supabase.com/docs/guides/database/database-linter?lint=0001_unindexed_foreign_keys).

The organization is using the free project slots. [Supabase's backup guidance](https://supabase.com/docs/guides/platform/backups) says automatic daily database backups are on paid plans and recommends regular offsite CLI dumps for free projects; database backups also exclude Storage object bytes. The existing encrypted database-plus-private-object tooling still needs a hosted capture, separately held keys, offsite copy, clean-target restore, hash/count comparison and measured recovery time before this project can hold real donations.
