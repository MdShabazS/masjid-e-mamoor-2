## Cross-phase items that can be missed

1. **Database and authorization are common gates.** Run all migrations in order on an isolated fresh project, then all nine scenarios as actual roles. Add direct REST/RPC denial, stale-account, idempotency and concurrent spend/claim/cap tests. The recent expense-correction SQL has only a source review and unexecuted scenario; its trigger transitions and effective totals require particular attention.
2. **Private files need a complete path.** QR image, expense bill/proof, meeting memo, receipt and report require verified upload bytes, MIME/size rules, restricted reads, object metadata, cleanup, encrypted backup and restore. A path or digest stored in SQL does not establish that the object exists or is private.
3. **Queued work needs a sender and operations.** The protected tick enqueues four job classes, but there is no deployment schedule, in-app push dispatcher, PDF renderer, Meta sender endpoint or failed-job dashboard. Keep WhatsApp disabled until owner/provider inputs exist.
4. **Correction propagation crosses phases.** A corrected posting must update effective balance, expense unpaid amount, monthly reminder, receipt validity, referral score, report revision and operator history consistently. Some SQL projections exist, but no end-to-end proof or published corrected documents do.
5. **Owner decisions remain dependencies.** Consent/privacy and retention; approver/revision/advance/salary scope; referral/multiple-payment points; public receipt disclosure and combined-score wording require recorded approval before real data publication. Real QR and account, masjid coordinate, content/contact, Business number/templates, Drive folder/key custodian and signed-device environment are activation/field inputs, not reasons to skip independent development.
6. **Prerequisite phase debt matters.** Phase 0 lacks a clean reproducible install/CI; Phase 2/3 lack signed-off complete contracts and fresh Auth/RLS proof. Those gaps block trustworthy Phase 4–12 exits even where a local screen compiles.
