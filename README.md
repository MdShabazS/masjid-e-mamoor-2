# Masjid E Mamoor 2

The Android app, web app and database for Masjid E Mamoor live in
[`fresh-build/`](fresh-build/README.md). Its README covers setup after cloning,
checks and environments. Run every Node, web, Android and database command from
that folder.

- What is done and what is left: [`fresh-build/PROJECT_STATUS.md`](fresh-build/PROJECT_STATUS.md)
- Requirements, decision register and acceptance criteria: [`docs/`](docs/README.md)
- CI: `.github/workflows/fresh-build-source.yml`
- Source backup scripts: `scripts/backup_project_source.py` and `scripts/verify_project_source_backup.py`

The earlier app, database and design files were removed on 25–26 October 2026.
Their history is still in Git, and the old app's last uncommitted work is on the
`archive/old-app-unsaved` branch.

Real-money launch stays NO-GO until the approvals, verified bank details,
production setup, signed APK, recovery drill and acceptance work in
`PROJECT_STATUS.md` are done.
