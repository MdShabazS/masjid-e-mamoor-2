# Masjid E Mamoor 2

The active implementation is in [`fresh-build/`](fresh-build/README.md). Run its
Node, web, Android and database commands from that directory as documented there.
The current release checklist is [`fresh-build/tasks.md`](fresh-build/tasks.md).

The root `docs/` directory contains historical requirements and decision records
used to reconcile the new build. It is not a second application. The superseded
root `apps/`, `packages/`, `supabase/` and pnpm workspace were removed on
25 October 2026; their committed history remains in Git. The verified local
pre-cleanup source archive is in `backups/` and is intentionally excluded from Git.

Real-money launch remains gated by the approvals, verified bank details,
production environment, signed APK, recovery drill and acceptance work listed
in the current release checklist.
